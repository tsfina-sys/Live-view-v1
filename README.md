# LiveView D6 — True 3D Landmarks

## Τι αλλάχθηκε

Στην D5 τα landmarks έμοιαζαν με κάρτες/ταμπέλες.
Στην D6:

- τα σημεία ενδιαφέροντος πατούν πάνω στην υδρόγειο,
- δεν εμφανίζονται ως τετράγωνα πλακίδια,
- σχεδιάζονται σαν μικρά 3D-style κτίρια/μνημεία,
- το όνομα δεν φαίνεται μόνιμα,
- το όνομα εμφανίζεται μόνο όταν πατήσεις το landmark.

## Παραδείγματα
- Παρθενώνας → μικρό temple
- Big Ben / Eiffel / Burj → tower
- κάστρα / φρούρια → castle
- πυραμίδες → ancient
- όρη / φυσικά σημεία → mountain
- στάδια / αμφιθέατρα → stadium

## Ενημέρωση
1. Αντικατάστησε όλα τα αρχεία του repository με τα αρχεία του ZIP.
2. Κάνε commit.
3. Άνοιξε μία φορά το GitHub Pages link και κάνε ανανέωση.
4. Κλείσε τελείως την εγκατεστημένη εφαρμογή και άνοιξέ την ξανά.
5. Αν βλέπεις την παλιά έκδοση, κάνε επανεγκατάσταση του PWA.
