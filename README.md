# LiveView MVP D1

Πρώτο λειτουργικό πρωτότυπο της ιδέας:

- χάρτης με διαθέσιμους χρήστες,
- κατάσταση «Διαθέσιμος / Μη διαθέσιμος»,
- προσεγγιστική αντί ακριβούς δημόσιας θέσης,
- δοκιμαστικό αίτημα ζωντανής εικόνας,
- επιλογή διάρκειας,
- τοπική δοκιμή πίσω/μπροστινής κάμερας,
- βασική μορφή PWA για κινητό.

## Τι ΔΕΝ κάνει ακόμα

Η D1 δεν συνδέει δύο πραγματικούς χρήστες και δεν μεταδίδει βίντεο μέσω Internet.
Οι χρήστες στον χάρτη είναι δοκιμαστικοί.

Για την πραγματική D2 χρειάζονται:

1. λογαριασμοί χρηστών,
2. βάση δεδομένων και Presence,
3. signaling μεταξύ δύο συσκευών,
4. WebRTC σύνδεση,
5. STUN/TURN server,
6. block, report και μηχανισμός διαχείρισης καταχρήσεων.

## Εκτέλεση σε υπολογιστή

Η απλή διπλή επιλογή του `index.html` μπορεί να δείξει τον χάρτη, αλλά η κάμερα
ενδέχεται να μη λειτουργήσει λόγω περιορισμών ασφαλείας του browser.

Προτεινόμενος τρόπος:

1. Άνοιξε γραμμή εντολών μέσα στον φάκελο.
2. Εκτέλεσε:

   python -m http.server 8000

3. Άνοιξε:

   http://localhost:8000

Το `localhost` επιτρέπεται συνήθως για δοκιμή κάμερας. Για πραγματική χρήση από
κινητό απαιτείται φιλοξενία με HTTPS.

## Προτεινόμενη συνέχεια D2

- React + TypeScript
- MapLibre GL JS
- Supabase Auth, Postgres και Realtime Presence
- WebRTC για βίντεο
- TURN server για αξιόπιστη σύνδεση εκτός τοπικού δικτύου
- ακριβής θέση μόνο στη συσκευή, δημόσια περιοχή με σκόπιμη απόκλιση
- χωρίς εγγραφή βίντεο στην πρώτη πραγματική έκδοση
