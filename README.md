# LiveView D2 PWA Fullscreen

Έκδοση διορθωμένη για εγκατάσταση στο κινητό ως πραγματικό PWA.

## Αλλαγές

- εικονίδια 192×192 και 512×512,
- maskable εικονίδιο Android,
- Apple touch icon,
- σωστό `manifest.json`,
- λειτουργία `fullscreen`,
- κουμπί «Εγκατάσταση» όταν το επιτρέπει ο browser,
- νέο service worker cache,
- παραμένουν όλες οι λειτουργίες του D1.

## Ανέβασμα στο GitHub

Αντικατάστησε όλα τα παλιά αρχεία του repository με τα αρχεία που βρίσκονται
μέσα σε αυτόν τον φάκελο.

## Σημαντικό στο κινητό

1. Διέγραψε την παλιά συντόμευση/εγκατάσταση LiveView.
2. Άνοιξε μία φορά το νέο GitHub Pages link στο Chrome.
3. Κάνε ανανέωση της σελίδας.
4. Πάτησε το κουμπί εγκατάστασης ή:
   Chrome ⋮ → Εγκατάσταση εφαρμογής.
5. Άνοιξε το LiveView από το νέο εικονίδιο της αρχικής οθόνης.

Η γραμμή διεύθυνσης του Chrome δεν θα εμφανίζεται. Η έκδοση ζητά επίσης
πλήρη οθόνη, ώστε σε συμβατές συσκευές Android να κρύβεται και η επάνω
γραμμή κατάστασης.
