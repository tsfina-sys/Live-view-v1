# LiveView D10 — Accounts & Supabase

Βάση: `LiveView_D9_REMOVE_LOCATION_CARD.zip`

## Νέα λειτουργία

- εγγραφή χρήστη με email, κωδικό και ψευδώνυμο,
- σύνδεση και αποσύνδεση,
- επαναφορά κωδικού,
- επεξεργασία ψευδωνύμου,
- πραγματική κατάσταση «Διαθέσιμος»,
- αποθήκευση μόνο προσεγγιστικής δημόσιας θέσης,
- φόρτωση πραγματικών διαθέσιμων χρηστών από τη βάση,
- ζωντανή ενημέρωση όταν αλλάζει η διαθεσιμότητα,
- Row Level Security μέσω του `SUPABASE_SETUP.sql`.

## Αρχεία ρύθμισης

- `SETUP_SUPABASE.md`
- `SUPABASE_SETUP.sql`
- `supabase-config.js`

Μέχρι να συμπληρωθεί το `supabase-config.js`, η εφαρμογή διατηρεί τους
δοκιμαστικούς χρήστες ώστε να μην εμφανίζεται κενή.
