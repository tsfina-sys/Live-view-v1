# LiveView D7 — Καθαρή υδρόγειος

## Αλλαγές

- Αφαιρέθηκαν εντελώς όλα τα αξιοθέατα.
- Αφαιρέθηκαν τα δεδομένα, τα σύμβολα και όλος ο κώδικας των landmarks.
- Η υδρόγειος παραμένει καθαρή, με τους διαθέσιμους χρήστες.
- Το πεδίο κατάστασης των διαθέσιμων χρηστών μετακινήθηκε χαμηλά αριστερά.
- Το πεδίο έγινε μικρότερο ώστε να μην καλύπτει τον χάρτη.
- Η επιλογή ακτίνας 5 / 10 / 25 / 50 / 100 km παραμένει στη λειτουργία «Κοντά μου».
- Η ένδειξη πηγών του χάρτη έγινε μικρό, συμπτυγμένο κουμπί πληροφοριών.

## Ενημέρωση GitHub / PWA

1. Αντικατάστησε όλα τα αρχεία του repository με τα αρχεία του ZIP.
2. Κάνε commit.
3. Άνοιξε το GitHub Pages link και κάνε μία ανανέωση.
4. Κλείσε πλήρως την εγκατεστημένη εφαρμογή και άνοιξέ την ξανά.
5. Αν παραμένει η D6, αφαίρεσε και εγκατέστησε ξανά το PWA.
