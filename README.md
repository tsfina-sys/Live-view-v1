# LiveView D12 — Είσοδος δοκιμής

Βάση: `LiveView_D11_LOGIN_FROM_START.zip`

## Διόρθωση

Η D11 απαιτούσε πραγματικό λογαριασμό πριν ανοίξει η υδρόγειος, αλλά το Supabase
δεν είχε ακόμη ρυθμιστεί. Η D12 προσθέτει:

- κουμπί `Είσοδος δοκιμής`,
- πρόσβαση στην υδρόγειο χωρίς λογαριασμό,
- εμφάνιση των δοκιμαστικών χρηστών,
- τοπική λειτουργία «Διαθέσιμος» για έλεγχο εμφάνισης,
- κανονική Σύνδεση / Εγγραφή παραμένει έτοιμη για όταν ρυθμιστεί το Supabase.

## Πού εμφανίζεται

1. Πάτησε `Είσοδος / Ρύθμιση λογαριασμού`.
2. Κάτω από τα πεδία Σύνδεσης / Εγγραφής εμφανίζεται `Είσοδος δοκιμής`.
3. Πάτησέ το για να μπεις άμεσα στην εφαρμογή.

Όταν ολοκληρωθεί η σύνδεση Supabase, η είσοδος δοκιμής κρύβεται αυτόματα.
