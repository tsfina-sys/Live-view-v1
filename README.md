# LiveView D11 — Login από την αρχική οθόνη

Βάση: `LiveView_D10_ACCOUNTS_SUPABASE.zip`

## Αλλαγές

- Αφαιρέθηκε εντελώς το κουμπί με το ερωτηματικό από τον χάρτη.
- Το αρχικό κουμπί γράφει `Σύνδεση / Εγγραφή` όταν δεν υπάρχει ενεργή συνεδρία.
- Πατώντας το, εμφανίζονται στην ίδια αρχική οθόνη:
  - Σύνδεση
  - Εγγραφή
  - Ξέχασα τον κωδικό
- Η υδρόγειος ανοίγει μόνο μετά από επιτυχημένη σύνδεση.
- Αν υπάρχει ήδη αποθηκευμένη ενεργή συνεδρία, το αρχικό κουμπί γράφει `Είσοδος`.
- Μετά τη σύνδεση, το προφίλ ανοίγει πατώντας το λογότυπο/όνομα `LiveView` επάνω αριστερά.
- Με την αποσύνδεση επιστρέφει στην αρχική οθόνη.

## Σημαντικό

Για πραγματική εγγραφή και σύνδεση πρέπει να ολοκληρωθεί η ρύθμιση Supabase:

- `SETUP_SUPABASE.md`
- `SUPABASE_SETUP.sql`
- `supabase-config.js`
