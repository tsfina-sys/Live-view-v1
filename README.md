# LiveView D9 — Χωρίς πλαίσιο «Η ΘΕΣΗ ΜΟΥ»

## Αλλαγές

- Αφαιρέθηκε εντελώς το μεγάλο κάτω πλαίσιο «Η ΘΕΣΗ ΜΟΥ».
- Η θέση του κινητού εξακολουθεί να χρησιμοποιείται εσωτερικά.
- Ο μπλε δείκτης θέσης παραμένει πάνω στον χάρτη.
- Η λειτουργία «Κοντά μου» συνεχίζει να δουλεύει κανονικά.
- Το μικρό πλαίσιο «Κοντά μου / Υδρόγειος / Περιοχή» μετακινήθηκε χαμηλά δεξιά.
- Η επιλογή εμβέλειας 5 / 10 / 25 / 50 / 100 km παραμένει.
- Η ένδειξη πηγών του χάρτη μετακινήθηκε χαμηλά ώστε να μην αφήνει μεγάλο κενό.

## Ενημέρωση

1. Αντικατάστησε όλα τα αρχεία του repository με τα αρχεία του ZIP.
2. Κάνε commit.
3. Άνοιξε το GitHub Pages link και κάνε ανανέωση.
4. Κλείσε πλήρως την εφαρμογή και άνοιξέ την ξανά.
