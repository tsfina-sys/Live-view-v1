# LiveView D4 — Σταθερή αρχική οθόνη

Η αυτόματη οθόνη εκκίνησης του Android/PWA εμφανίζεται μόνο όσο φορτώνει η εφαρμογή
και δεν μπορούμε να ορίσουμε αξιόπιστα τη διάρκειά της.

Η D4 προσθέτει δική της αρχική οθόνη μέσα στην εφαρμογή:

- παραμένει ορατή χωρίς χρονικό όριο,
- κλείνει μόνο όταν πατήσεις «Είσοδος»,
- μετά ζητά άδεια τοποθεσίας,
- έπειτα εμφανίζεται η υδρόγειος και η θέση σου,
- διατηρεί όλες τις λειτουργίες της D3.

## Ενημέρωση

Αντικατάστησε όλα τα αρχεία του repository με τα αρχεία του ZIP και κάνε commit.
Μετά άνοιξε το GitHub Pages link, κάνε ανανέωση και κλείσε/άνοιξε ξανά την
εγκατεστημένη εφαρμογή.

Αν βλέπεις ακόμη την προηγούμενη έκδοση, αφαίρεσε την εφαρμογή και εγκατέστησέ
την ξανά.
